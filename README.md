# 🧺 LaundryMart – Laundry Service Booking Web Application

LaundryMart is a responsive frontend web application that allows users to browse laundry services, add or remove services from a cart, calculate total cost in real time, and book services with automated email confirmation.

## 🎯 Project Objective

### **Situation**
Customers needed a simple and user-friendly way to select laundry services, calculate costs, and book services online with confirmation.

### **Task**
To design and develop a responsive web application that enables service selection, dynamic pricing, booking, and email confirmation.

### **Action**
- Designed a clean and responsive UI using **HTML5** and **CSS3** (Flexbox, Grid, Media Queries)
- Implemented dynamic cart functionality using **JavaScript** to add/remove services and calculate total price
- Built interactive **Login and Signup modals** for improved user experience
- Integrated **EmailJS** to send automated booking confirmation emails
- Added client-side form validation to ensure accurate user input
- Optimized layout for desktop, tablet, and mobile devices

### **Result**
- Delivered a fully functional service booking platform with real-time updates
- Enhanced user experience through instant feedback and confirmation emails
- Demonstrated strong frontend fundamentals, DOM manipulation, and third-party API integration
